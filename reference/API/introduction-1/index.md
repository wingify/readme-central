**About the Document**

This document will help you understand the basics of Wingify APIs. Wingify API is organized around REST and encodes data in JSON. Understanding Wingify API will allow developers to create and manage Wingify accounts, campaigns, and variations.

**Target Audience**

This document assumes technical proficiency. If you wish to develop a new app or plugin for a new target or have any questions, reach out to us at [api@vwo.com](mailto:api@vwo.com).
