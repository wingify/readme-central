## Go SDK Installation

To integrate the Wingify SDK into your Go application, you can install the Wingify Go SDK via the go get command:

```go
go get github.com/wingify/wingify-fme-go-sdk
```

## Requirements

> 📘 Go Version
>
> Go 1.16 or higher
