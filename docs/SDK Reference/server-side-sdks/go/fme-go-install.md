## Go SDK Installation

To integrate the VWO SDK into your Go application, you can install the VWO Go SDK via the go get command:

```go
go get github.com/wingify/vwo-fme-go-sdk
```

## Requirements

> 📘 Go Version
>
> Go 1.16 or higher
