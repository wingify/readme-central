## React Native SDK Installation

To integrate the FE SDK into your React application, you can do this via cocoapods. Simply add the following line to your Podfile

```shell Bash
# get the sdk
yarn add wingify-fme-react-native-sdk

# Or via npm
npm install wingify-fme-react-native-sdk

# install cocoapods dependencies for ios
cd ios && pod install
```

## Requirements

> 📘 iOS Version & Android API Level
>
> iOS version 12.0 and above
>
> Android API level 21 and above
